Data, privacy, limits & deployment

Firebase Realtime Database saves aggregate venue counts, server timestamps and observation methods. No visitor identifiers or precise locations are recorded. Counts expire from the public current-signal view after 24 hours; historical aggregate reports remain available for calibration. All capacities are speculative planning assumptions, doubled from previous working midpoints and not legal occupancy limits. GitHub Pages hosts this file; Firebase provides the shared live database and authentication.
